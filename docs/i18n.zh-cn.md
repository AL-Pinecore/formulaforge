# 国际化（i18n）

定位：中英文界面切换、系统语言检测、MathLive 词条覆盖、零代码新增语言。

## 涉及文件

- `app/composables/useI18n.ts` — i18n 核心
- `app/locales/en.ts` / `app/locales/zh.ts` — 语言包
- `app/plugins/mathlive.client.ts` — MathLive 词条注入与 locale 同步

## 工作机制

### 语言包自动发现

`useI18n.ts` 用 `import.meta.glob('../locales/*.ts', { eager: true })` 自动加载所有 locale 文件。每个文件导出 `default`（含 `languageCode`/`displayName` + UI 翻译）和 `mathlive`（MathLive 词条覆盖）。发现时校验 `languageCode`/`displayName`/`mathlive` 是否齐全，缺则跳过。

`availableLocales` 从字典推导，语言切换栏直接渲染，无需硬编码语言清单。

### `t()` 解析与回退

`t(key, params?, fallback?)` 支持点路径（`t('category.basic')` → `dictionary.category.basic`）。当前语言查不到时回退到 `en`，再回退到 `fallback`，最后回退到 key 本身。`{name}` 占位符由 `interpolate` 用 `params` 替换。

### 语言检测与持久化

`readStoredLocale()` 读 localStorage（`formulaforge.locale`），无效回退 `detectSystemLocale()`（`navigator.language` 精确/前缀匹配），再回退 `en`。`setLocale` 校验合法性、写入 localStorage、更新 `document.documentElement.lang`。

### MathLive 词条

`mathlive.client.ts` 里 `MathfieldElement.strings = mathliveStrings`（按当前 locale 取），并 `watch(locale)` 同步 `MathfieldElement.locale`。这样数学字段里的菜单/提示也跟着语言切换。

## 设计取舍

- **glob 自动发现**：新增语言只需丢一个 locale 文件，无需改组件/插件（README 的「添加语言」章节详述了约定）。
- **en 作为单一回退源**：`t()` 的 fallback 链保证任何缺失键都有英文兜底。

## 已知边界

- 参数插值只支持 `{word}` 命名占位符，不支持复数/性别等 ICU 特性（`ponytail:` 层面，当前文案用不到）。
- locale 文件名仅作整理，`languageCode` 才是语言标识。
